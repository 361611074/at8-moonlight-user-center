# 漫步白月光用户中心 (moonlight-user-center)

轻量、主题无关的 WordPress 用户中心插件，兼容 **Astra 主题** 与 **Elementor 页面构建器**。提供前端登录、注册、找回密码、账户仪表盘、资料编辑、头像上传等完整功能，并内置 PayPal / Stripe 会员支付。

- 官网：https://www.at8.fun/
- 版本：1.7.1
- 授权：GPL-2.0-or-later
- 最低要求：WordPress 5.8 / PHP 7.4

## 功能特性

- **前端登录 / 注册 / 找回密码**：短代码驱动，任意主题可用，样式作用域限定 `.mluc-`，与主题无冲突。
- **账户中心仪表盘**：侧栏导航 + 概览 / 资料编辑 / 退出，账户 Tab 通过过滤器 `mluc_account_tabs` 可扩展（可挂接商城订单等）。
- **资料编辑**：昵称、个人网站、简介、密码修改。
- **前端头像上传**。
- **Elementor 组件**：登录表单、注册表单、用户资料卡。
- **界面文案全量可自定义**：后台「用户中心 → 设置 → 界面文案（账户中心）」可改写账户中心全部前台文字（v1.4.3 起全量开放），留空回退默认值，支持多语言。
- **多语言**：内置简体中文 / 繁体（香港、台湾）/ 英文翻译文件。

## 在线支付（会员开通）

后台「用户中心 → 设置 → 在线支付」可配置：

- **PayPal**：Smart Buttons，服务端 capture 后校验金额并自动开通会员。
- **Stripe**：Checkout 托管结账，回跳自动校验开通；可选 Webhook（`/wp-json/mluc/v1/stripe-webhook`）兜底。
- 货币代码后台可配（默认 USD），零小数货币（JPY/KRW 等）自动处理。

## 短代码

| 短代码 | 说明 |
| --- | --- |
| `[mluc_login]` | 登录表单 |
| `[mluc_register]` | 注册表单 |
| `[mluc_lostpassword]` | 找回密码 |
| `[mluc_account]` | 账户中心 |

## 安装

1. 将本仓库内容上传至 `wp-content/plugins/moonlight-user-center/`；
2. 在 WordPress 后台「插件」中启用「漫步白月光用户中心」；
3. 进入「用户中心 → 设置」按需配置界面文案与在线支付。

## 兼容性

- 与 Astra 主题无冲突（样式作用域限定 `.mluc-`）；
- 与 Elementor 集成，提供专用组件；
- 不依赖主题全局函数，可独立运行。
